# Arjun Portfolio

A React + Vite portfolio for Arjun K Lapoji.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personal details to update

- `src/components/Hero.jsx` — headline and intro
- `src/components/About.jsx` — about and education
- `src/components/Skills.jsx` — skills
- `src/components/Projects.jsx` — project descriptions
- `src/components/Passion.jsx` — interests
- `src/components/Contact.jsx` — email and social links

The 3D robot is rendered locally with React Three Fiber. It does not require an external model file.
